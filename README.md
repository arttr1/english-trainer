# english-trainer

Персональный скилл для Claude Code: коучинг по английскому для разработчика/дата-сайентиста с упором на грамматику, словарный запас (особенно техническую лексику) и продуктивные навыки (письмо/говорение), которые отстают от понимания (чтение/слушание). Дополнительно умеет превращать выученные слова и ошибки в настоящие Anki-карточки для spaced repetition вне чата.

## Стек, на котором это работает

- **Claude Code** — сам скилл, роутит запросы, ведёт локальный профиль ученика
- **Anki Desktop** (macOS/Windows/Linux) — держит настоящую коллекцию карточек. Единственный компонент, с которым Claude Code говорит напрямую
- **AnkiConnect** (add-on для Anki Desktop, код `2055492159`) — открывает `http://localhost:8765`, локальный HTTP/JSON-RPC API для создания карточек. Anki Desktop должен быть запущен (можно свёрнут), пока идёт синк со скиллом
- **AnkiWeb** — бесплатный облачный аккаунт, к которому подключены и Desktop, и телефон. Просто источник истины для синхронизации, скилл с ним не взаимодействует напрямую
- **AMGI** ([antigluten/amgi](https://github.com/antigluten/amgi)) — open-source iOS-клиент на официальном Rust-движке Anki. Без него можно использовать платный AnkiMobile из App Store — работает так же. AMGI не в сторе, ставится сайдлодом (например через LiveContainer из `.ipa` в [релизах](https://github.com/antigluten/amgi/releases))

Путь карточки: Claude Code → AnkiConnect → Anki Desktop → (Sync) → AnkiWeb → (Sync) → AMGI/AnkiMobile на телефоне.

## Установка

1. Скопируй папку `english-trainer/` в директорию скиллов Claude Code:
   ```bash
   cp -r english-trainer ~/.claude/skills/
   ```
2. Поставь [Anki Desktop](https://apps.ankiweb.net/), создай/залогинься в аккаунт AnkiWeb (кнопка Sync).
3. `Tools → Add-ons → Get Add-ons...` → код `2055492159` (AnkiConnect) → перезапусти Anki.
4. Проверь, что AnkiConnect слушает:
   ```bash
   curl http://localhost:8765
   # {"apiVersion": "AnkiConnect v.6"}
   ```
5. (Опционально, для карточек на телефоне) поставь AMGI или AnkiMobile на iPhone, залогинься в тот же аккаунт AnkiWeb.

Профиль ученика (`data/profile.json`) создаётся автоматически при первом обращении к скиллу — не нужно создавать руками. В репозитории лежит только `data/profile.example.json` как образец структуры; реальный `profile.json` в `.gitignore`, потому что содержит личный прогресс.

## Структура

```
english-trainer/
├── SKILL.md                    — координатор: решает что делать, ведёт профиль
├── references/
│   ├── grammar-drills.md       — грамматика: типичные ошибки рус→eng + упражнения
│   ├── vocabulary.md           — словарный запас: SRS-методика + тематические списки
│   ├── production.md           — письмо/говорение/разговорная практика
│   ├── tech-reading.md         — работа с документацией/статьями/лекциями
│   └── anki-cards.md           — логика генерации и заливки Anki-карточек
├── scripts/
│   ├── profile.py              — CLI для чтения/записи профиля (слова, ошибки, уровень, сессии)
│   └── anki_sync.py            — CLI, который говорит с AnkiConnect (добавление карточек)
└── data/
    ├── profile.example.json    — пустой шаблон структуры профиля
    └── profile.json            — твой реальный профиль (создаётся сам, в .gitignore)
```

## Как пользоваться — коучинг

Просто пиши Claude Code что хочешь — скилл сработает на естественные формулировки:

- "дай грамматическое упражнение" / "проверь это предложение"
- "хочу выучить новые слова по теме devops"
- "проверь как я написал этот PR description"
- "давай попрактикуем разговор — представь что ты ревьюер кода"
- "разбери эту статью: <ссылка>" / "найди что почитать про transformers"
- "продолжи с прошлого раза" — скилл сам посмотрит профиль и предложит что актуально

## Как пользоваться — Anki-карточки

- "добавь новые слова в анки" — возьмёт всё не отправленное из vocabulary queue (`profile.py anki-pending`), сформирует Basic-карточки (обычно с обратной стороной EN↔RU) и зальёт через AnkiConnect
- "сделай карточку на эту ошибку" — во время грамматического разбора превратит конкретную повторяющуюся ошибку в Cloze-карточку (пропуск на месте исправления + объяснение правила)
- "закинь слова из этой статьи в анки" — во время tech-reading разбора слова, отмеченные как незнакомые, идут в Cloze-карточки на основе реального предложения из текста, а не в вакууме
- "закинь всё, что накопилось" — пушит весь бэклог, а не только текущую сессию

Технически это работает так:
```bash
# что ещё не отправлено в Anki
python3 scripts/profile.py anki-pending --kind vocab

# добавить одну карточку
python3 scripts/anki_sync.py add-basic --front "obsolete" --back "устаревший" --example "This API is obsolete." --tags "vocab" --reversed
python3 scripts/anki_sync.py add-cloze --text "The model started to {{c1::overfit}} after epoch 40." --back-extra "overfit — переобучаться"

# массово из JSON-файла (см. формат в docstring anki_sync.py)
python3 scripts/anki_sync.py add-batch --file cards.json

# отметить как отправленное, чтобы не задвоить при следующем запуске
python3 scripts/profile.py anki-mark-word "obsolete" "<note_id из ответа add-basic>"
```

Все карточки уходят в одну плоскую колоду `English`, с тегами `vocab`/`mistake` + тема/категория — удобно фильтровать в самом Anki. Подробная логика (когда Basic, когда Cloze, откуда берутся карточки) — в `references/anki-cards.md`.

## Профиль и приватность

`data/profile.json` — обычный локальный JSON-файл, живёт там же, где установлен скилл, никуда не отправляется сам по себе (кроме содержимого, которое ты явно просишь залить в Anki). Он в `.gitignore` в этом репозитории.

Посмотреть профиль вручную:
```bash
python3 scripts/profile.py show
```

## Известные грабли

- **Пример в reversed-карточке спойлерит ответ** — если положить `Example: ...` внутрь поля Back у стандартной модели "Basic (and reversed card)", обратная карточка (RU→EN) покажет всё поле Back как вопрос — то есть пример с английским ответом внутри увидит сразу же, до попытки вспомнить. Скилл использует для этого свою модель `Basic RU-EN with Example` с отдельным полем Example, видимым только на стороне ответа у обеих карточек — `anki_sync.py` создаёт её сам при первом обращении. Не используй стандартную reversed-модель для карточек с примером.
- **На AMGI поля склеиваются без пробела на вопросе** — две отдельные причины, обе в нативном рендерере AMGI (не в самих данных):
  1. Обёртка `<div class="example">...</div>` — AMGI распознаёт границы блоков только по закрывающим тегам (`</div>`, `<br>`, `<hr>`), не по открывающим, так что текст перед открывающим `<div>` сливается с ним.
  2. `<hr id="answer">` (стандартный атрибут Anki-шаблонов) — regex AMGI для `<hr>` требует, чтобы перед `>` были только пробелы; любой атрибут ломает распознавание, и весь ответ склеивается с Front без разделителя (например "to accomplishвыполнить, достичь, осуществить").

  Обе причины проверены напрямую по исходнику `antigluten/amgi` (`CardComplexity.swift`, `NativeCardContent.swift`). Шаблоны модели используют только чистые `<br><br>` и `<hr>` без атрибутов — при правке шаблона карточек в Anki не добавляй `<div>`-обёртки или `id`/`class` на `<hr>`.
- **Anki Desktop зависает на "Tools → Add-ons"** — если это случилось сразу после установки, попробуй переустановить свежий `.dmg`/`.exe` с [официального сайта](https://apps.ankiweb.net/) поверх — известная проблема Qt WebEngine на некоторых системах, переустановка обычно чинит.
- **AnkiConnect недоступен** — Anki Desktop должен быть реально запущен (свёрнут — ок, закрыт — не ок) в момент, когда скилл пытается что-то залить.
- **AMGI не в App Store** — только собранный `.ipa` из [релизов](https://github.com/antigluten/amgi/releases) (unsigned), нужен сайдлодинг (LiveContainer/AltStore/TrollStore и т.п.). Проще и без гимнастики — платный официальный [AnkiMobile](https://apps.apple.com/app/id373493387).
- **AMGI и AnkiWeb** — в онбординге нет отдельной кнопки "AnkiWeb", только "Custom Server" / "Use Locally". Впиши `https://ankiweb.net` в поле Custom Server и залогинься обычным аккаунтом AnkiWeb — сработает (движок общий с оригинальным Anki, включая обработку шардинга AnkiWeb).

## Если что-то не триггерится

Если скилл не подхватывается на какой-то запрос — можно явно попросить: "используй english-trainer skill". Также можно скорректировать описание в `SKILL.md` (поле `description` во frontmatter) — это самое важное поле для того, чтобы Claude понимал, когда скилл релевантен.
